快捷键

点击输入框后直接按下组合键。键盘与鼠标可同时设置，任意一个都能触发。鼠标支持中键、侧键（后退 / 前进），可配合 Ctrl / Alt / Shift；右键需配合修饰键。Backspace 清除。提示：鼠标侧键在浏览器里本身是「后退 / 前进」，Hopsnap 无法拦截，截图前页面可能已经后退，建议侧键配合 Ctrl / Alt 使用。Windows 11 默认把 PrintScreen 交给系统截图工具，要用它请先在 Windows 设置 → 辅助功能 → 键盘 里关掉「使用 Print Screen 键打开屏幕截图」。

声音

系统声音录制电脑正在播放的声音
麦克风录制时可在控制条上随时静音
麦克风设备
建议戴耳机录制。同时开着系统声音和麦克风时，喇叭放出的声音会被麦克风再录一次，听起来像回音。只想录电脑里的声音，关掉麦克风即可。
选中的麦克风设备是「立体声混音」类设备。它录的是喇叭输出，不是你的声音。录系统声音请用上面的「系统声音」开关，麦克风设备请选真正的麦克风。

这个项目是开源的：https://github.com/chaichungsang/Hopsnap

文件工具的视频处理使用 LGPL ffmpeg（动态链接，没有静态打进本程序）。图片处理使用 sharp / libvips（LGPL-3.0-or-later）。

遇到问题时，把日志文件 hopsnap.log 发给开发者，就能看到具体原因。

  • 截图：区域 / 窗口 / 全屏，原生分辨率（支持 4K、高 DPI）
  • 标注：矩形、椭圆、箭头、画笔、荧光笔、马赛克、文字、序号，可撤销重做、可拖动修改
  • 输出：复制到剪贴板、保存 PNG / JPG、钉在屏幕（贴图）
  • 录屏：区域 / 全屏，MP4（H.264）或 GIF，1080p / 2K / 4K，24–60 fps，系统声音 + 麦克风
  • 演示：鼠标光圈、点击波纹、聚光灯、摄像头画中画（录屏和会议共享都看得到）
  • 快捷键：键盘与鼠标（中键 / 侧键）都能自定义
  • 文件工具：转格式、压缩、改尺寸、剪视频、转 GIF、合成 PDF，都在本机处理
  • 中文 / English 界面，默认跟随系统
