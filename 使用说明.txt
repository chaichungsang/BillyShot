BillyShot 1.3.5 —— 免费截图 + 录屏 + 贴图
==========================================

一、安装
--------
Windows（推荐）
  · Windows\BillyShot-Setup-1.3.3.exe   双击安装（1.3.4 / 1.3.5 只改了 Mac，Windows 仍是 1.3.3），自动创建桌面和开始菜单快捷方式
    装过旧版本的直接安装覆盖即可，设置和截图历史都会保留。
  · Windows\卸载BillyShot-Uninstall.exe  双击就能找到这台电脑上的 BillyShot 并卸载（见「九、卸载」）
  第一次运行如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」（因为没有购买代码签名证书）。

Mac
  · Mac/BillyShot-1.3.5-mac-AppleSilicon.zip  M1 / M2 / M3 / M4 芯片
  · Mac/BillyShot-1.3.5-mac-Intel.zip         Intel 芯片
  解压后把 BillyShot 拖进「应用程序」。第一次打开如果提示「无法验证开发者」：
    系统设置 → 隐私与安全性 → 最下面点「仍要打开」；
    或者在终端运行：xattr -cr /Applications/BillyShot.app
  然后在 系统设置 → 隐私与安全性 里允许：
    · 屏幕与系统录音（截图、录屏必须）
    · 辅助功能（只有使用「鼠标快捷键」「点击波纹」时需要）
    · 麦克风（只有录麦克风时需要）
    · 摄像头（只有使用「摄像头画中画」时需要）
  屏幕录制授权以后要退出 BillyShot 再重新打开才生效（只关设置窗口不算，它还在菜单栏里）：
    提示框和 设置 → 常规 →「macOS 权限」里都有「重新打开 BillyShot」按钮，点一下就行。
    辅助功能打开后几秒内自动生效，不用重开。（1.3.5）
  设置 → 常规 →「macOS 权限」能看到屏幕录制、辅助功能现在是不是已允许。
  开关已经是打开的，BillyShot 却还是一直提示要授权（多半是旧版本留下的授权记录）：
    点「修复权限」（提示框或 设置 → 常规 里都有）：自动清掉 BillyShot 的旧记录，
    然后在系统设置里重新打开一次开关，再点「重新打开 BillyShot」。
    还不行的话点「复制诊断信息」，把内容发给我们。
  不在「应用程序」文件夹里运行（例如直接从下载文件夹打开）时，BillyShot 会建议移过去，
    否则授权容易对不上。
  从这一版起 Mac 版用固定证书签名，以后升级不用再重新授权。
  macOS 15 及以上，系统可能隔一段时间问一次「是否继续允许录屏」，点「允许」就行，这是系统自己的提醒。

运行后 BillyShot 常驻在右下角托盘（Mac 在顶部菜单栏），没有主窗口。
单击托盘图标 = 截图；双击 = 打开设置；右键托盘图标 = 菜单（录屏、贴图、历史、语言、设置、退出）。

界面语言（中文 / English）
  · 默认跟随系统：电脑是中文（简体或繁体）就显示中文，其他语言显示英文
  · 手动切换：设置 → 常规 →「界面语言 · Language」，或者右键托盘图标 →「语言 / Language」
  · 切换后立即生效，不用重启


二、默认快捷键（都可以在 设置 → 快捷键 里改，键盘和鼠标都行）
--------------------------------------------------------------
                         Windows            Mac
  截图（框选 + 编辑）     Alt + A            ⌃ ⌘ A
  全屏截图直接复制        Alt + Shift + A    ⌃ ⌘ ⇧ A
  区域录屏 / 停止         Alt + R            ⌃ ⌘ R
  全屏录屏 / 停止         Alt + Shift + R    ⌃ ⌘ ⇧ R
  贴图（钉住剪贴板图片）   Alt + P            ⌃ ⌘ P

  * 微信默认也用 Alt+A。BillyShot 每次启动都会检查：如果快捷键被其他软件占用，
    会自动换成 Ctrl+Alt+A（或其他空闲的组合）并弹出通知，设置里也会显示红点，你可以自己改。
  * 鼠标快捷键：在设置里点「鼠标」那一格，然后按鼠标中键或侧键（可以同时按住 Ctrl/Alt/Shift）。
    注意侧键在浏览器里本身是「后退 / 前进」，BillyShot 拦不住，建议侧键配合 Ctrl / Alt 使用。
  * 想用 PrintScreen 键：Windows 11 默认把它给了系统截图工具，先到
    Windows 设置 → 辅助功能 → 键盘 关掉「使用 Print Screen 键打开屏幕截图」，再在 BillyShot 里设置。


三、截图界面（和微信一样）
--------------------------
  拖动鼠标           框选区域；鼠标悬停会自动识别窗口，单击直接选中
  拖动边框 / 8 个点   调整选区；在选区里拖动可移动选区
  Enter / 双击选区   完成，复制到剪贴板（可以直接粘贴到微信、Word 等）
  Esc               退出
  右键               取消当前工具 → 重新框选 → 退出

  工具栏：矩形(R) 椭圆(E) 箭头(A) 画笔(P) 荧光笔(H) 马赛克(M) 文字(T) 序号(N)
          撤销(Ctrl+Z) 重做(Ctrl+Y) · 录制这个区域 · 贴图 · 保存(Ctrl+S) · 完成
  · 选工具后下面会出现粗细和颜色
  · 按住 Shift 画正方形 / 正圆 / 45° 箭头
  · 单击已画的标注可以选中、拖动、改颜色，Delete 删除；双击文字可重新编辑
  · 马赛克有「涂抹」和「框选」两种
  · 放大镜显示像素和颜色，按 C 复制颜色值；方向键微调选区
  · 如果复制到剪贴板失败（剪贴板被其他软件占用），会弹出提示，截图在 设置 → 历史 里还能找回


四、录屏
--------
  · 按区域录屏快捷键 → 框选区域 → 选 MP4 或 GIF、系统声音、麦克风 → 开始录制
    区域录屏会记住你上次选的格式；全屏录屏用 设置 → 录屏 里的「默认格式」。
  · 录制时区域有红色边框，下方有控制条：暂停 / 停止保存 / 放弃；再按一次快捷键也能停止
  · 分辨率：原画 / 4K / 2K / 1080p / 720p，帧率 24 / 30 / 60。录屏工具栏上的「1080p」「30 fps」可以直接点开选，
    会显示实际输出尺寸；选择会记住（和 设置 → 录屏 是同一个设置）。默认 1080p。
    注意：输出不会超过屏幕本身的分辨率，要录 4K，屏幕要是 4K。
    电脑性能跟不上设定帧率时会提示「录制帧率偏低」，可以调低帧率或分辨率。
  · 录制中途出错（例如显卡驱动重置）时，已经录好的部分会保留下来
  · 文件默认保存在 「视频/BillyShot」 文件夹，截图保存在 「图片/BillyShot」
  · 按停止后控制条会显示「正在保存…」和进度，好了变成绿色的「已保存」，可以直接点「打开文件夹」或「播放」
    （20 秒不理它会自动收起）。录制中文件夹里的文件名是「….mp4.part」，保存完才变成 .mp4——看到 .mp4 就是好了。
    万一录到一半程序被关掉或电脑断电，下次打开 BillyShot 会自动把录到的部分恢复成 .mp4。（1.3.2）
  · Mac 录系统声音需要 macOS 13 以上
  · 声音怎么选：
      只想录电脑里播放的声音（视频、音乐）→ 只开「系统声音」，关掉「麦克风」，音质最干净
      要同时录自己说话 → 两个都开，并且戴耳机。不戴耳机的话，喇叭的声音会被麦克风再录一次，
      听起来像回音、发闷（工具栏会显示「建议戴耳机」）
      麦克风设备不要选「立体声混音 / Stereo Mix」，那录的是喇叭输出，不是你的声音


五、应用图标（1.2.4 新增）
------------------------
  · 默认是新的头像版图标。想换回原来的紫色玻璃图标：设置 → 常规 → 应用图标，点「紫色玻璃版」，随时可以换回来。
  · Windows：托盘、设置窗口、通知，以及桌面 / 开始菜单 / 任务栏上的 BillyShot 快捷方式会一起换。
    桌面图标如果没马上变，等几秒或在桌面按 F5。安装文件夹里 BillyShot.exe 本身的图标不变（那是打包时定的）。
    以后升级安装时快捷方式会被重建成头像版，BillyShot 启动后会自动改回你选的图标。
  · Mac：菜单栏、程序坞（打开设置时）和「应用程序」里的 BillyShot.app 会一起换。
    如果系统不让改「应用程序」里的图标，设置页会提示；可以在访达里选中 BillyShot → 显示简介，
    把 BillyShot.app 里 Contents/Resources/app.asar.unpacked/assets/logos/purple/mac.png 拖到左上角的小图标上。
  · 头像版在托盘 / 菜单栏里显示为圆形头像；紫色版在 Mac 菜单栏仍是黑白的取景框图标（随深浅色自动变）。


六、主题配色（1.2.6 新增）
------------------------
  · 设置 → 常规 → 主题配色，点一下立即生效，截图工具栏的强调色也会跟着变。共 9 套：
      午夜紫（原来的）  黑金  石墨（极简黑白）  深海蓝  森林绿  玫瑰粉  纯白（浅色侧栏）
      透明玻璃  Matrix 代码雨（黑底荧光绿，侧栏有代码雨，只有深色）
  · 默认是「跟随图标」：头像图标配黑金，紫色图标配午夜紫。选了某一套之后就固定用那一套。
  · 透明玻璃：Windows 11（22H2 以后）和 Mac 上窗口背后会透出桌面（系统毛玻璃）；
    Windows 10 没有系统毛玻璃，显示为彩色渐变 + 半透明卡片的效果。
    Mac 上换到 / 换走「透明玻璃」时，设置窗口会自动重开一下（位置不变），这是正常的。（1.3.4 修好了 Mac 上的重影）
  · 右边的下拉框可以选「深浅色：跟随系统 / 浅色 / 深色」，每套配色都有浅色和深色两种（Matrix 只有深色）。


七、演示录屏（1.3.0 新增）
------------------------
  录课、讲解软件、开会共享屏幕时用。这些效果直接画在屏幕上，所以录出来的视频里有，
  Zoom / Teams / 腾讯会议 共享屏幕时观众也看得到；截图时会自动隐藏，不会出现在截图里。

  · 鼠标光圈：鼠标周围一圈半透明光圈。点击波纹：每次点击像水面一样荡开几道波纹（有高光和阴影），
    左键偏红、右键偏蓝（颜色可改）。显卡不支持水波纹时，改成两三道半透明白圈，不再用粉色单圈。（1.3.5）
    在 设置 → 演示 打开，颜色、大小可调。开着「录屏时自动显示」时，录屏一开始就显示、录完自动收起。
  · 演示模式（不录屏也要用，例如开会共享屏幕讲解）：托盘菜单勾选「演示模式」。
    第一次用时如果光圈和波纹都没开，会自动帮你打开（录屏时也会显示，可以在设置里关）。
  · 聚光灯：整个屏幕变暗，只有鼠标周围亮着。托盘菜单 / 设置页 / 录制控制条上都能开关。
    录制中打开的聚光灯，录完自动关掉。
  · 摄像头画中画：
      区域录屏时，在工具栏点「摄像头」；全屏录屏用 设置 → 演示 →「录屏时显示摄像头」。
      圆窗默认在录制区域右下角，可以拖动（会记住位置）；鼠标移上去有 大小 / 形状 / 关闭 三个按钮。
      拖到录制区域外面时圆窗边框变橙色（区域外不会被录进去）。
      不录屏也能打开：托盘菜单「摄像头画中画」，或设置页「预览」。
      有些摄像头同一时间只能给一个程序用：Zoom / Teams / 微信 正开着摄像头时 BillyShot 可能打不开，
      控制条上会显示原因，录屏照常进行。
  · 录制控制条多了三个按钮：鼠标效果、聚光灯、摄像头，录制中随时开关。
  · 快捷键：演示模式和聚光灯默认没有快捷键（不占用你其他软件的按键），
    需要的话在 设置 → 快捷键 里设置。
  · Mac：点击波纹需要「辅助功能」权限，摄像头需要「摄像头」权限（第一次用时系统会问）。


八、其他
--------
  · 截图历史：设置 → 历史 / 剪贴板，点图片重新复制
  · 贴图：滚轮缩放，拖动移动，双击或 Esc 关闭，右键有透明度 / 复制 / 保存
  · 出问题时：设置 → 关于 → 打开日志，把 billyshot.log 发给 Billy Chai
  · 完全免费、不联网、无广告、无水印、无账号

九、卸载
--------
Windows（任选一种）
  · 开始菜单 →「卸载 BillyShot」（英文系统叫 Uninstall BillyShot）
  · 双击安装包旁边的 卸载BillyShot-Uninstall.exe
  · Windows 设置 → 应用 → 已安装的应用 → BillyShot → 卸载
  卸载时会问「要同时删除设置和截图历史吗？」
    是 = 卸载并删除设置；否 = 卸载但保留设置（以后重装还能接着用）；取消 = 不卸载
  你保存的截图和录屏视频（「图片/BillyShot」「视频/BillyShot」）永远不会被删除。
  免安装版（zip）：退出 BillyShot 后直接删除那个文件夹即可。

Mac
  · 右键菜单栏的 BillyShot 图标 → 退出，然后把「应用程序」里的 BillyShot 拖到废纸篓
  · 想连设置一起删：在访达按 ⇧⌘G，前往 ~/Library/Application Support/BillyShot，删除这个文件夹
  · 系统设置 → 隐私与安全性 里的 BillyShot 授权可以顺手去掉


源代码在 BillyShot-源代码-1.3.5.zip 里（Electron），自己修改后可以重新打包：
  npm install
  npm run dist:win     （Windows 安装包）
  npm run dist:mac     （Mac）
