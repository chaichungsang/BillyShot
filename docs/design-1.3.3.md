# BillyShot 1.3.3 — 点击波纹改成透明水波纹

## 需求（Benji，2026-10-04）
- 点击波纹要像真的水波纹，**透明**的，不是彩色圆圈。
- 选型过程：CSS 彩色圈（3 种）→ 「不像水」→ WebGL 光影水波（高光 + 阴影）→ 「真实的水波纹是透明的」→ 选定 **透明折射水波**（预览页 B）。
- 保留旧样式作为选项：设置 → 演示 →「波纹样式」：水波纹（默认）/ 单圈（旧样式）。

## 做法
### 演示层（`src/renderer/present-layer.js`，`present.html` 的 `<canvas id="water">`）
- 每次点击 = 一个往外扩散的波包：前沿位置 `8 + 150·t` px，高斯包络 σ=22px，波长 24px，持续 1.6 秒（实际看得见约 1 秒），振幅随时间和半径衰减。
- 片元着色器算出高度对半径的斜率 → 法线 → 光照（光从左上来）：
  - **折射**：用点击时抓到的那块屏幕当纹理，按斜率把采样点错开（最多约 16 px × 斜率）。错开很少的地方输出透明，直接看到下面真实的画面，所以整体是透明的。
  - **反光**：迎光的波峰上一道细亮线（50% 混入左键 / 右键颜色），背光处最多暗 6%。
  - 没有画面时（抓屏失败 / Mac 没有屏幕录制权限）只画反光和最多 12% 的淡影子。
- 每个波纹只画外接方块；`env < 0.002` 的像素直接丢弃；没有波纹时停止绘制并把画布缩成 1×1。
- WebGL 第一次点击时才创建；创建失败 / 着色器失败 → 退回单圈。处理 `webglcontextlost` / `restored`（期间退回单圈，恢复后重建）。
- 最多同时 12 个波纹；每个波纹自己的纹理，结束时删除。
- 画面到达后折射在 0.12 秒内淡入（波纹本身点下去就开始，前 0.08 秒振幅从 0 升上来，几乎看不见）。

### 主进程（`src/present.js`）
- 点击时：`present:click {id, x, y, button, refract}`；`refract` = 样式是水波纹且能抓屏（有 node-screenshots；Mac 要屏幕录制权限已授予；同时在抓的不超过 2 个）。
- 抓屏：`Monitor.fromPoint`（Windows 先 `dipToScreenPoint`）→ `captureImage()` → 裁出点击处上下左右各 220 DIP → `toRaw()`（RGBA）→ `present:patch {id, x, y, w, h（DIP）, pw, ph（物理像素）, data}`。按抓到的图片尺寸 / 屏幕 DIP 尺寸算缩放；比例异常（混合缩放偶发抓错屏）就不折射。
- 抓到的画面里包含演示层自己（光圈、正在播的其他波纹），影响很小：新波纹前 0.08 秒几乎透明，光圈只在中心附近。
- `presentStatus` 里多了 `lastPatchMs`（最近一次抓屏耗时）。

### 设置
- `present.rippleStyle`: `'water'`（默认）| `'single'`；非法值按 water 处理。老用户升级自动是水波纹。
- 设置页「点击波纹」说明改为「点击时像水波一样荡开，左键和右键颜色不同」，下面加「波纹样式」下拉。中英文都加了。

### 测试专用
- `BILLYSHOT_TEST` 且未打包时加 `enable-unsafe-swiftshader`（云端测试机没有显卡）；`BILLYSHOT_TEST_NOGL=1` 不加（测试退回单圈）；`BILLYSHOT_TEST_NOPATCH=1` 不抓屏（对照组）。

## 已知限制 / 需要真机确认
- 点击后画面立刻变化（例如弹出菜单）时，波纹经过的地方会短暂折射出点击前的画面（约 1 秒内、只在波峰附近）。Benji 选型时已知。
- Windows 4K 抓整屏的耗时（再裁剪）；如果很慢，折射会晚一点淡入，不影响点击。
- Mac：没有屏幕录制权限时没有折射，只有反光。
- 透明窗口 + WebGL 在 Windows / Mac 上的合成、Zoom 共享里的效果。
