Hopsnap 2.0 (呱咔) — free screenshots, screen recording and pins
==================================================================

As of 2.0, BillyShot is called Hopsnap (呱咔 in Chinese) and has a frog for a mascot. The whole interface was
redesigned; features and shortcuts are unchanged. Upgrading from BillyShot: the first launch copies your settings
and screenshot history over, keeps your save folders, and leaves the old folders untouched.

1. Install
----------
Windows
  · Hopsnap-Setup-2.0.0.exe            double-click to install (desktop + Start menu shortcuts); installs over old versions
  · Hopsnap-2.0.0-Windows-x64-win.zip  portable, just unzip
  · Uninstall-Hopsnap.exe              uninstall helper (see "9. Uninstall")
  If Windows shows "Windows protected your PC", click "More info → Run anyway" (no paid code-signing certificate).

Mac
  · Hopsnap-2.0.0-mac-AppleSilicon.zip   M1 / M2 / M3 / M4
  · Hopsnap-2.0.0-mac-Intel.zip          Intel
  Unzip and drag Hopsnap into Applications. If macOS says the developer can't be verified:
    System Settings → Privacy & Security → scroll down → "Open Anyway";
    or in Terminal: xattr -cr /Applications/Hopsnap.app
  On first launch the Permissions helper opens:
    Step 1  Allow "Screen Recording" — needed for screenshots and recording. Click "Open System Settings", find Hopsnap
            in the list and turn it on. The helper checks every second; once it's on, the button becomes "Reopen Hopsnap"
            (macOS only hands the permission to a freshly opened process).
    Step 2  "Accessibility" (optional) — only for mouse-button shortcuts and click ripples. Takes effect immediately.
    Microphone and camera: macOS asks the first time you use them.
  If the switch is already on but Hopsnap keeps asking (usually a stale record from an older version):
    Permissions helper → "Still not working?" → "Repair permissions", then turn the switch on once more.
    Still stuck? "Copy diagnostics" and send it to us.
  You can reopen the helper any time from Settings → General or the Get started page; while the permission is missing
  it's also the first item in the tray menu.
  On macOS 15+ the system may periodically ask whether to keep allowing screen recording — click Allow; that's macOS.

Hopsnap lives in the tray (menu bar on Mac, a black-and-white frog) with no main window.
Click the tray icon = screenshot; double-click = settings; right-click = menu (record, presenting, files, settings, quit).

Language: follows the system by default; Settings → General → Language to switch. The Chinese UI calls the app
呱咔, the English UI Hopsnap; macOS permission lists always show "Hopsnap".
Appearance: light / dark follows the system, or fix it in Settings → General. The screenshot toolbar is always dark.


2. Default shortcuts (change any of them in Settings → Shortcuts; keyboard or mouse)
-----------------------------------------------------------------------------------
                                  Windows            Mac
  Screenshot (select + edit)      Alt + A            ⌃ ⌘ A
  Full-screen screenshot to clipboard  Alt + Shift + A    ⌃ ⌘ ⇧ A
  Record region / stop            Alt + R            ⌃ ⌘ R
  Record full screen / stop       Alt + Shift + R    ⌃ ⌘ ⇧ R
  Pin clipboard image             Alt + P            ⌃ ⌘ P
  File Tools                      Ctrl+Shift+Alt+F   ⌃ ⌥ F

  * WeChat also uses Alt+A. Hopsnap checks on every launch; if a shortcut is taken it switches to a free combination
    and notifies you (a red dot shows in Settings).
  * Mouse shortcuts: click the "Mouse" cell in Settings, then press the middle or a side button (optionally with
    Ctrl/Alt/Shift). Side buttons are Back/Forward in browsers and can't be intercepted — combine them with Ctrl/Alt.
  * PrintScreen: Windows 11 gives it to Snipping Tool by default; turn that off in
    Windows Settings → Accessibility → Keyboard first.
  * The Get started page lists all shortcuts; click one to edit.


3. Screenshot editor
--------------------
  Drag                 select a region; hovering highlights windows, click to select one
  Drag edges / handles resize; drag inside to move
  Enter / double-click done — copies to the clipboard
  Esc                  exit
  Right-click          cancel tool → reselect → exit

  Toolbar: Rectangle(R) Ellipse(E) Arrow(A) Pen(P) Highlighter(H) Mosaic(M) Text(T) Number(N)
           Undo(Ctrl+Z) Redo(Ctrl+Y) · Record this region · Pin · Save(Ctrl+S) · Done
  · Width and color appear under the toolbar once a tool is selected; hold Shift for squares / circles / 45° arrows
  · Click a shape to select, drag, recolor or Delete it; double-click text to edit
  · Mosaic has "brush" and "box" modes
  · The magnifier shows pixels and color; press C to copy the color; arrow keys nudge the selection
  · If copying fails, you're told, and the shot is still in Settings → Recent screenshots


4. Recording
------------
  · Press the region shortcut → select → choose MP4 or GIF, system audio, microphone → Start.
    Region recording remembers your last format; full-screen uses the default format in Settings → Recording.
  · The countdown is a frog puffing its cheeks. While recording the region has a red frame and a control bar:
    pause / stop & save / discard. Pressing the shortcut again also stops.
  · Resolution: native / 4K / 2K / 1080p / 720p; 24 / 30 / 60 fps — pick directly from the toolbar. Output never
    exceeds the screen's own resolution. If the machine can't keep up you'll see "Low frame rate".
  · If recording fails midway (e.g. GPU reset) what was recorded is kept; after a crash the .part is recovered as .mp4.
  · Files go to Movies/Hopsnap (Videos\Hopsnap), screenshots to Pictures/Hopsnap — BillyShot users keep their folders.
  · After stop the bar shows "Saving…" then a green "Saved" with Open folder / Play.
  · System audio on Mac needs macOS 13+.
  · On a Mac with a notch, the recording timer sits in the notch (or just under it). The tray icon stays.
    The control bar hides while recording and comes back when you stop, for save and playback.
    Displays without a notch get a black pill. Hover the notch to screenshot or start recording.
  · Audio tips: computer sound only → system audio only; your voice too → both, and wear headphones
    (otherwise speaker sound is recorded twice as echo). Don't pick "Stereo Mix" as the microphone.


5. Presenting
-------------
  For lessons, demos and screen sharing. Effects are drawn on the screen itself, so they appear in recordings and in
  Zoom / Teams shares; they hide automatically during screenshots.
  · Cursor halo: a soft ring around the pointer. Click ripples: water-like ripples on each click, reddish for left,
    bluish for right (colors adjustable). Turn on in Settings → Presenting; options appear once a switch is on.
  · Tray menu → Presenting: Halo / Click ripples / Spotlight / Camera, any time.
  · Spotlight: dims the screen except around the pointer; turned on during a recording, it turns off afterwards.
  · Camera bubble: click "Camera" on the region toolbar, or Settings → Presenting → "Show camera while recording".
    Drag it (position is remembered); hover for size / shape / close; the frame turns orange outside the recorded area.
    If Zoom / Teams / WeChat holds the camera, the bar tells you and the recording continues.
  · Mac: click ripples need Accessibility, the camera needs Camera permission (macOS asks the first time).


6. File Tools
-------------
  Convert, compress images, resize, turn video into MP4, compress or trim video, make a GIF, or combine
  images and PDFs into one PDF. Everything stays on this computer.
  · Open from the tray menu → File → File Tools, or the shortcut above.
  · On Mac, hold Shift and drag files: an action arc opens beside the pointer (turn it off in
    Settings → General). No system permission is required.
  · GIFs can be at most 15 seconds; trim a longer video first.
  · HEIC: Mac uses the system decoder. Windows needs the HEIF Image Extensions from the Microsoft Store.
  · Video uses LGPL ffmpeg (dynamically linked). Images use sharp / libvips.


7. Everything else
------------------
  · Recent screenshots: the last 4 on the Get started page (click to copy again); all of them in Settings → Recent screenshots
  · Pins: scroll to zoom, drag to move, double-click or Esc to close, right-click for opacity / copy / save
  · Updates: Settings → About → "Check for updates". By default Hopsnap asks GitHub once a day for the latest version
    number (nothing is uploaded); a new version adds a tray item and notifies once. Turn it off in Settings → General.
  · Problems: Settings → About → Open log file and send hopsnap.log to Billy Chai
  · Free, no ads, no watermark, no account, nothing uploaded


8. Upgrading from BillyShot
---------------------------
  · Windows: install 2.0; settings and history migrate automatically. Uninstall the old BillyShot afterwards.
  · Mac: 2.0 has a new bundle id (com.hopsnap.app), so macOS treats it as a new app — Screen Recording must be
    allowed once more; the Permissions helper walks you through it. Quit the old BillyShot.app and trash it.
  · Your saved screenshots and recordings are never touched.


9. Uninstall
------------
Windows (any of these)
  · Start menu → "Uninstall Hopsnap"
  · Double-click Uninstall-Hopsnap.exe
  · Windows Settings → Apps → Installed apps → Hopsnap → Uninstall
  You'll be asked whether to delete settings and screenshot history too. Saved screenshots and videos are never deleted.
  Portable version: quit Hopsnap and delete the folder.

Mac
  · Right-click the frog in the menu bar → Quit, then drag Hopsnap from Applications to the Trash
  · To remove settings as well: Finder ⇧⌘G → ~/Library/Application Support/Hopsnap and delete the folder
  · Optionally remove Hopsnap from System Settings → Privacy & Security
