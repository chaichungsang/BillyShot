呱咔 Hopsnap 2.0 —— 免费截图 + 录屏 + 贴图
============================================

2.0 起 BillyShot 改名为「呱咔 / Hopsnap」，吉祥物是一只小青蛙。界面全部重做，功能和快捷键不变。
从 BillyShot 升级：第一次打开会自动把设置和截图历史搬过来，保存位置保持原样，旧文件夹不动。

一、安装
--------
Windows
  · Hopsnap-Setup-2.0.0.exe      双击安装，自动创建桌面和开始菜单快捷方式；装过旧版本的直接覆盖安装
  · Hopsnap-2.0.0-Windows-x64-win.zip   免安装版，解压就能用
  · Uninstall-Hopsnap.exe        卸载小工具（见「九、卸载」）
  第一次运行如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」（没有购买代码签名证书）。

Mac
  · Hopsnap-2.0.0-mac-AppleSilicon.zip   M1 / M2 / M3 / M4 芯片
  · Hopsnap-2.0.0-mac-Intel.zip          Intel 芯片
  解压后把 Hopsnap 拖进「应用程序」。第一次打开如果提示「无法验证开发者」：
    系统设置 → 隐私与安全性 → 最下面点「仍要打开」；
    或者在终端运行：xattr -cr /Applications/Hopsnap.app
  打开后会弹出「权限助手」：
    第 1 步 允许「屏幕录制」—— 截图、录屏都需要。点「打开系统设置」，在列表里找到 Hopsnap，把开关打开。
            助手每秒检查一次，开了自动变成「重新打开呱咔」按钮——这是 macOS 的硬要求，权限只给重新打开后的进程。
    第 2 步 「辅助功能」（可选）—— 只有用鼠标快捷键、点击波纹时才需要，开了马上生效，不用重开。
    麦克风、摄像头：第一次录麦 / 开摄像头时系统自己会问。
  开关已经是打开的、呱咔却一直提示（多半是旧版本留下的授权记录）：
    权限助手 →「还是不行？」→「修复权限」，然后在系统设置里重新打开一次开关。还不行就「复制诊断信息」发给我们。
  权限助手随时能从 设置 → 常规 / 开始页 里再打开；没权限时托盘菜单第一行也是它。
  macOS 15 及以上，系统可能隔一段时间问一次「是否继续允许录屏」，点「允许」就行，这是系统自己的提醒。

运行后呱咔常驻在右下角托盘（Mac 在顶部菜单栏，黑白小青蛙），没有主窗口。
单击托盘图标 = 截图；双击 = 打开设置；右键 = 菜单（录屏、演示、文件、设置、退出）。

界面语言（中文 / English）
  · 默认跟随系统：电脑是中文就显示中文，其他语言显示英文；设置 → 常规 →「界面语言 · Language」可手动切换
  · 中文界面里产品叫「呱咔」，英文叫 Hopsnap；系统设置的权限列表里永远显示 Hopsnap

外观
  · 浅色 / 深色跟随系统，也可以在 设置 → 常规 → 外观 固定；截图工具栏和录制条始终是深色


二、默认快捷键（都可以在 设置 → 快捷键 里改，键盘和鼠标都行）
--------------------------------------------------------------
                         Windows            Mac
  截图（框选 + 编辑）     Alt + A            ⌃ ⌘ A
  全屏截图直接复制        Alt + Shift + A    ⌃ ⌘ ⇧ A
  区域录屏 / 停止         Alt + R            ⌃ ⌘ R
  全屏录屏 / 停止         Alt + Shift + R    ⌃ ⌘ ⇧ R
  贴图（钉住剪贴板图片）   Alt + P            ⌃ ⌘ P
  文件工具                Ctrl+Shift+Alt+F   ⌃ ⌥ F

  * 微信默认也用 Alt+A。呱咔每次启动都会检查：快捷键被其他软件占用时自动换成空闲的组合并通知你，设置里也会显示红点。
  * 鼠标快捷键：在设置里点「鼠标」那一格，然后按鼠标中键或侧键（可以同时按住 Ctrl/Alt/Shift）。
    侧键在浏览器里本身是「后退 / 前进」，呱咔拦不住，建议侧键配合 Ctrl / Alt 使用。
  * 想用 PrintScreen 键：Windows 11 默认把它给了系统截图工具，先到
    Windows 设置 → 辅助功能 → 键盘 关掉「使用 Print Screen 键打开屏幕截图」，再在呱咔里设置。
  * 开始页上有所有快捷键的一览，点一下就跳到修改。


三、截图界面
------------
  拖动鼠标           框选区域；鼠标悬停会自动识别窗口，单击直接选中
  拖动边框 / 8 个点   调整选区；在选区里拖动可移动选区
  Enter / 双击选区   完成，复制到剪贴板（可以直接粘贴到微信、Word 等）
  Esc               退出
  右键               取消当前工具 → 重新框选 → 退出

  工具栏：矩形(R) 椭圆(E) 箭头(A) 画笔(P) 荧光笔(H) 马赛克(M) 文字(T) 序号(N)
          撤销(Ctrl+Z) 重做(Ctrl+Y) · 录制这个区域 · 贴图 · 保存(Ctrl+S) · 完成
  · 选工具后下面会出现粗细和颜色；按住 Shift 画正方形 / 正圆 / 45° 箭头
  · 单击已画的标注可以选中、拖动、改颜色，Delete 删除；双击文字可重新编辑
  · 马赛克有「涂抹」和「框选」两种
  · 放大镜显示像素和颜色，按 C 复制颜色值；方向键微调选区
  · 复制到剪贴板失败时会提示，截图在 设置 → 最近截图 里还能找回


四、录屏
--------
  · 按区域录屏快捷键 → 框选区域 → 选 MP4 或 GIF、系统声音、麦克风 → 开始录制
    区域录屏会记住你上次选的格式；全屏录屏用 设置 → 录屏 里的「默认格式」。
  · 倒计时是一只鼓着腮帮子数数的青蛙；录制时区域有红色边框，下方有控制条：暂停 / 停止保存 / 放弃；再按一次快捷键也能停止
  · 分辨率：原画 / 4K / 2K / 1080p / 720p，帧率 24 / 30 / 60。录屏工具栏上的「1080p」「30 fps」可以直接点开选。
    输出不会超过屏幕本身的分辨率。电脑性能跟不上时会提示「录制帧率偏低」，可以调低帧率或分辨率。
  · 录制中途出错（例如显卡驱动重置）时，已经录好的部分会保留下来；录到一半断电，下次打开会自动恢复成 .mp4
  · 文件默认保存在 「视频/Hopsnap」，截图保存在 「图片/Hopsnap」（从 BillyShot 升级的保持原来的文件夹）
  · 按停止后控制条显示「正在保存…」和进度，好了变成绿色「已保存」，可以直接「打开文件夹」或「播放」
  · Mac 录系统声音需要 macOS 13 以上
  · Mac 有刘海时，录制计时贴在刘海两侧（或刘海正下方），托盘图标还在。录的时候控制条先藏起来，
    按停止后再出现，用来保存和播放。没有刘海的显示器上是一颗黑胶囊。悬停刘海可以截图或开始录制。
  · 声音怎么选：只录电脑声音 → 只开「系统声音」；要录自己说话 → 两个都开并戴耳机（不然会有回音）；
    麦克风设备不要选「立体声混音 / Stereo Mix」


五、演示
--------
  录课、讲解软件、开会共享屏幕时用。效果直接画在屏幕上，录屏里有，Zoom / Teams / 腾讯会议 共享时观众也看得到；截图时自动隐藏。
  · 鼠标光圈：鼠标周围一圈半透明光圈。点击波纹：每次点击像水面一样荡开几道波纹，左键偏红、右键偏蓝（颜色可改）。
    设置 → 演示 里打开，颜色、大小可调；相关选项只在开关打开后才出现。
  · 托盘菜单 → 演示：鼠标光圈 / 点击波纹 / 聚光灯 / 摄像头 随时开关
  · 聚光灯：整个屏幕变暗，只有鼠标周围亮着。录制中打开的聚光灯，录完自动关掉。
  · 摄像头画中画：区域录屏时在工具栏点「摄像头」；全屏录屏用 设置 → 演示 →「录屏时显示摄像头」。
    圆窗可以拖动（会记住位置），鼠标移上去有 大小 / 形状 / 关闭；拖到录制区域外边框变橙色。
    Zoom / Teams / 微信 正占用摄像头时可能打不开，控制条上会显示原因，录屏照常。
  · Mac：点击波纹需要「辅助功能」权限，摄像头需要「摄像头」权限（第一次用时系统会问）。


六、文件工具
------------
  转格式、压缩图片、改尺寸、视频转 MP4 / 压缩 / 剪头尾 / 转 GIF、把图片和 PDF 合成一个 PDF。
  全部在这台电脑上完成，不上传。
  · 打开：托盘菜单 → 文件 → 文件工具，或上面的快捷键
  · Mac 还可以按住 Shift 把文件拖到光标旁，弹出一圈动作（设置 → 常规里可以关掉）。不需要系统权限
  · GIF 最长 15 秒，更长的视频要先剪一段
  · HEIC：Mac 用系统解码；Windows 需要先装 Microsoft Store 的「HEIF 图像扩展」
  · 视频处理用 LGPL 的 ffmpeg（动态链接），图片用 sharp / libvips


七、其他
--------
  · 最近截图：开始页显示最近 4 张，点一下重新复制；设置 → 最近截图 看全部
  · 贴图：滚轮缩放，拖动移动，双击或 Esc 关闭，右键有透明度 / 复制 / 保存
  · 检查更新：设置 → 关于 →「检查更新」。默认每天自动问一次 GitHub 有没有新版本（只请求版本号，不上传任何内容），
    有新版本时托盘菜单多一行、通知一次；可以在 设置 → 常规 关掉
  · 出问题时：设置 → 关于 → 打开日志文件，把 hopsnap.log 发给 Billy Chai
  · 完全免费、无广告、无水印、无账号、不上传任何内容


八、从 BillyShot 升级
--------------------
  · Windows：直接安装 2.0，设置和历史自动迁移；旧的 BillyShot 建议卸载（开始菜单 → 卸载 BillyShot）
  · Mac：2.0 是新的 bundle id（com.hopsnap.app），系统把它当新应用——第一次打开要重新授权一次屏幕录制，权限助手会带你做；
    旧的 BillyShot.app 退出后拖到废纸篓即可
  · 保存的截图和录屏不会动


九、卸载
--------
Windows（任选一种）
  · 开始菜单 →「卸载呱咔」（英文系统叫 Uninstall Hopsnap）
  · 双击 Uninstall-Hopsnap.exe
  · Windows 设置 → 应用 → 已安装的应用 → Hopsnap → 卸载
  卸载时会问「要同时删除设置和截图历史吗？」是 = 删除设置；否 = 保留设置；取消 = 不卸载
  你保存的截图和录屏视频永远不会被删除。免安装版退出后直接删文件夹。

Mac
  · 右键菜单栏的青蛙 → 退出，然后把「应用程序」里的 Hopsnap 拖到废纸篓
  · 想连设置一起删：访达按 ⇧⌘G，前往 ~/Library/Application Support/Hopsnap，删除这个文件夹
  · 系统设置 → 隐私与安全性 里的 Hopsnap 授权可以顺手去掉
